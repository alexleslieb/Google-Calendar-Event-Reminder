Google Calendar Event Reminder

Premise:
Imagine creating and inviting many persons to a Google Calendar event, only for them to say they didn't remember the event was happening until 30 minutes before the scheduled time. As it turns out, when you create a Google Calendar event, you can only set additional reminders for yourself, and not the guests added to the event. 

This program serves as an experimental solution to that problem.

Solution:
Create an application that will routinely access the calendar of a given user, create additional reminders for calendar event guests and send notification emails to those guests when the time for those reminders comes. 

Technologies:
.NET Core
C#
SQL Server
